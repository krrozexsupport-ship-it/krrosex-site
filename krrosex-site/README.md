## 🚀 How to Deploy on GitHub Pages (Free Hosting)

### Method 1: Via GitHub Desktop or Web Upload (Easiest)

1. **Create a New GitHub Repository:**
   - Log into [GitHub](https://github.com/).
   - Click the **+** icon in the top-right corner &rarr; **New repository**.
   - Name it (for example: `rosex-website` or `rose-x-site`).
   - Choose **Public** &rarr; Click **Create repository**.

2. **Upload Website Files:**
   - On the repository page, click **Add file** &rarr; **Upload files**.
   - Drag and drop **all files and the `assets/` folder** from `c:\Users\Admin\AndroidStudioProjects\KRRoseX\website\` into GitHub.
   - Click **Commit changes**.

3. **Enable GitHub Pages:**
   - Go to your repository's **Settings** tab.
   - In the left sidebar, click **Pages** (under the "Code and automation" section).
   - Under **Build and deployment** &rarr; **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` (or `master`), folder `/ (root)`, and click **Save**.

4. **Your Live Website URL:**
   - After 1–2 minutes, GitHub Pages will display your live URL:
   ```
   https://<your-github-username>.github.io/<repository-name>/
   ```

- **Google Play Developer Program Policies** (User Data, Financial/Reward disclosures, Account Deletion).

- **India (Digital Personal Data Protection Act 2023 & IT Act 2000)** (Grievance redressal, purpose limitation).

- **Japan (APPI)**.
- **South Korea (PIPA)**.
